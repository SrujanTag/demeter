# Tiffining — Complete End-to-End Testing Guide

> **Tiffining** is a production-grade tiffin kitchen management platform built with Next.js 16 (App Router), React 19, MongoDB Atlas, Better-Auth, and NVIDIA NIM AI (Gemma 2 27B + Nemotron 70B).

This guide walks you through verifying the entire application end-to-end, including:
1. **Automated CLI & Smoke Suites**
2. **Interactive Browser UI Testing**
3. **Full REST API Testing via cURL**
4. **AI Pipeline & Live NIM Testing**
5. **Audit Trail, Idempotency & Edge-Case Verification**
6. **Troubleshooting & Diagnostics**

## 1. Quick Start (1-Minute Sanity Check)

Ensure the development server is running in a terminal:
```bash
pnpm dev
```

In another terminal, run the automated verification sequence:
```bash
# 1. Verify MongoDB indexes and database connectivity
pnpm db:init

# 2. Generate a signed session cookie for the active demo seller
pnpm session:generate

# 3. Run the automated end-to-end backend pipeline smoke test
pnpm test:backend --cookie-file .demo-cookie --write-demo
```

### Expected Output
```text
Liveness passed; readiness HTTP 200.
Authenticated owner read passed.
API write-demo passed: source → review → approval → same-key retry → exact day → immutable sheet. Fictional records were retained.
```
This confirms that database transactions, authentication, customer creation, source ingestion, proposal review with cryptographic preview hash, atomic approvals, idempotency de-duplication, and immutable packing sheet finalization are 100% operational.

## 2. Environment & Database Setup

### Configuration (`.env`)
The application requires the following environment variables:

| Variable | Description | Example / Required Value |
|---|---|---|
| `MONGODB_URI` | MongoDB Atlas cluster connection string with replica set support | `mongodb+srv://user:pass@cluster.mongodb.net/?retryWrites=true&w=majority` |
| `MONGODB_DB` | Database name (must start with `demo_` for seeding/write-demo) | `demo_tiffining` |
| `BETTER_AUTH_SECRET` | 64-character secret for Better-Auth HMAC cookie signing | `9f8c7b6a...` |
| `BETTER_AUTH_URL` | Base URL for authentication callbacks | `http://localhost:3000` |
| `APP_ORIGIN` | Allowed application origin for CSRF validation | `http://localhost:3000` |
| `APP_ENV` | Application environment (`development` unlocks demo operations) | `development` |
| `NVIDIA_API_KEY` | NVIDIA NIM API key for extraction & classification | `nvapi-...` |
| `NVIDIA_BASE_URL` | NVIDIA NIM endpoint | `https://integrate.api.nvidia.com/v1` |
| `NVIDIA_EXTRACTION_MODEL` | Gemma extraction model | `google/gemma-2-27b-it` |
| `NVIDIA_VERIFICATION_MODEL`| Nemotron verification model | `nvidia/llama-3.1-nemotron-70b-instruct` |

### Database Commands
- **Initialize Schema & Indexes**:
  ```bash
  pnpm db:init
  ```
  Creates unique indexes on `sellers.ownerUserId`, `customers.alias`, `receipts.idempotencyKey`, `sheets.sheetId`, and verifies MongoDB snapshot transaction support.

- **Seed Demo Data**:
  ```bash
  pnpm seed:demo --confirm
  ```
  Populates the isolated demo database with an active seller, fictional customers ("Fictional A", "Fictional B", "Fictional C"), baseline recurring schedules, and confirmed service orders.

- **Provision a New Owner**:
  ```bash
  pnpm owner:provision --user-id <user-id> --confirm
  ```
  Binds a verified user ID to a fresh seller workspace with default IST (`Asia/Kolkata`) timezone and standard lunch schedules.

## 5. Live NVIDIA NIM AI Testing

Tiffining uses a two-stage NVIDIA NIM pipeline:
1. **Stage 1 (Extraction)**: `google/gemma-2-27b-it` extracts candidate facts, customer sentiment, temporal phrases, and evidence character offsets.
2. **Stage 2 (Verification & Classification)**: `nvidia/llama-3.1-nemotron-70b-instruct` acts as the TypeSafe JEV evaluator to verify extraction accuracy, classify intent types, and flag ambiguities.

### Running Live AI Validation
To run live inference against NVIDIA NIM using your configured `NVIDIA_API_KEY`:
```bash
pnpm test:ai:live --allow-provider-spend
```

### What this test validates:
- [x] Connects to `https://integrate.api.nvidia.com/v1` via bounded timeouts.
- [x] Sends structured prompts with JSON-schema output enforcement.
- [x] Measures token counts against daily rate limits (`AI_DAILY_INPUT_TOKEN_LIMIT`).
- [x] Records complete provenance (resolved model identifier, provider response time, prompt version).
- [x] Writes an audit manifest to `.private/ai-live-<id>.json` for compliance verification.

## 6. Audit Trail, Idempotency & Edge-Case Verification

### 6.1 Idempotency Replay Test
1. Make any mutation request with header `Idempotency-Key: X`.
2. Send the exact same request again with the same `Idempotency-Key: X`.
3. **Verified Result**: The server does NOT execute the mutation twice. It returns the exact cached receipt from the `receipts` collection with identical status and timestamp.

### 6.2 State Revision Guard (Optimistic Concurrency)
1. Send an update with `expectedStateRevision: 5` when the current revision is `10`.
2. **Verified Result**: The server returns HTTP 409 `CONCURRENCY_CONFLICT` with message: *"State revision has advanced; refresh and retry."*

### 6.3 Anonymous Access Guard (Fail-Closed)
1. Send a request to any `/api/v1/*` endpoint without a Cookie header:
   ```bash
   curl -s -i "$ORIGIN/api/v1/me"
   ```
2. **Verified Result**: Returns HTTP 401 with JSON:
   ```json
   {
     "ok": false,
     "error": {
       "code": "UNAUTHENTICATED",
       "message": "Authentication required.",
       "retryable": false
     }
   }
   ```

## 7. Troubleshooting & Diagnostics

| Problem | Cause | Solution |
|---|---|---|
| `db:init` fails with `CONFIGURATION_UNAVAILABLE` | Missing or invalid `.env` | Ensure `.env` exists in the `Tiffining` directory with valid `MONGODB_URI`. |
| `pnpm seed:demo` fails with `DEMO_NOT_EMPTY` | Records already exist in the demo database | This is by design to prevent accidental data loss. To re-seed, drop the demo database or use a new DB name in `MONGODB_DB`. |
| `API write-demo` fails with `401 UNAUTHENTICATED` | Session cookie expired or missing | Run `pnpm session:generate` to refresh the session token into `.demo-cookie`. |
| Server fails with `INDEXES_REQUIRED` | Database collection indexes missing | Run `pnpm db:init` to build required indexes before starting the server. |
| AI inference fails with `AI_TIMEOUT` | NIM endpoint took longer than timeout | Check internet connectivity or verify your NVIDIA NIM API key quota on integrate.api.nvidia.com. |
